# Study of Truth

Aplicativo web estático e responsivo para leitura e estudo bíblico, marcações por capítulo, genealogias e comparação de pessoas em uma linha do tempo.

## Uso

Abra `index.html` em um navegador ou publique o conteúdo diretamente em um serviço de hospedagem estática.

Os dados do estudo são salvos no próprio navegador. Use as opções **Exportar** e **Importar** da página inicial para criar e restaurar backups em JSON.
